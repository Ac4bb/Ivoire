# Licences et crédits audio

Les enregistrements ci-dessous conservent leurs licences respectives. La licence MIT d’Ivoire couvre le code original.

Pour la version web, Ivoire a converti les échantillons utilisés de WAV vers **Ogg Vorbis** avec libvorbis (qualité 8). La conversion conserve les canaux stéréo, la fréquence d’échantillonnage et le nombre de trames de chaque enregistrement.

## Salamander Grand Piano V3

Enregistrements d’**Alexander Holm**, banque d’origine 48 kHz / 24 bits sous **Creative Commons Attribution 3.0 Unported**. La version web utilise 120 échantillons à 48 kHz. La hauteur des notes est ajustée à la lecture. En cas de redistribution, conservez le titre, le crédit, les notices et le lien de licence, et indiquez les adaptations éventuelles.
